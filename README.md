# 📐 مبادرة تعزيز مهارات الرياضيات الأساسية

مرحباً بكم في الصفحة الرسمية للمبادرة التعليمية الهادفة لتعزيز مهارات الرياضيات الأساسية، وتنمية مهارات التفكير والتحصيل الدراسي لدى الطالبات.

---

## 🎯 أهداف المبادرة
* إتقان مهارات الجمع والطرح الأساسية بتمكن.
* توفير أدلة إرشادية وأوراق عمل تفاعلية ومبسطة.
* رفع مستوى دقة الحل ومتابعة تقدم الطالبات.

---

## 📂 محتويات المبادرة
* **الخطط والتحضيرات:** تجدون هنا الخطط الزمنية والتحضير الخاص بالمهارات.
* **أوراق العمل والأنشطة:** نماذج لأنشطة رياضية وأوراق عمل قابلة للطباعة والتنزيل.

---
*صُممت هذه المبادرة لدعم العملية التعليمية وتوفير مصادر مرجعية دائمة.*
